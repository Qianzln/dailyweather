# DailyWeather v0.1.53 修复日志

> 日期：2026-10-13
> 目标：实机反馈两条——云层看不出在动；阴天显示晴天背景。

## 1. 阴天显示晴天背景（场景分组错判）

根因链：小米天气码 `2` = 阴 → `Providers.weatherCodeToSkycon` 映射为 `CLOUDY`
→ 文案表 SkyconMap 显示「阴」→ 但 `OppoSceneKey.groupFor` 里
`contains("CLOUDY")` 把它分进多云族 56（`56_2_cloudy-noon`：蓝底 + 4 朵云），
观感就是「文字阴天、背景晴天」。

修复：`OVERCAST` 或 `CLOUDY`（彩云/小米词表都表"阴"）→ 组 5（阴 overcast 预设，
灰调天空 + 满云）；多云族 56/58/101 只接 `PARTLY_CLOUDY_*`（文案=多云）。

## 2. 云层平移漂移重建

根因：原始 pack.json 里云**没有平移动画**——全场景动画只有太阳光晕 fadeIn/fadeOut
与雷闪 animator；云的"动"全靠着色器噪声形变
（`u_time × _NoiseSpeedX × 0.1` ≈ 0.015 uv/s 的边缘起伏），肉眼读作"不在动"。

修复（OppoSceneRenderer）：云实体（`e.cloud != null`）在模型矩阵阶段加
右→左缓慢平移 + 环绕回场：
- 遍历区间 = `2 × (1 + scaleX)`（云完整出屏再从右侧回场）；
- 速度按深度分层（视差）：z≈-0.7（最远）≈300s 穿屏，z≈0.6（最近）≈150s 穿屏；
- 云贴图四边 alpha 渐隐到 0（CLAMP_TO_EDGE），滑出/滑入屏幕边缘无硬切；
- 着色器内部的噪声形变保留，与平移叠加（形变 + 位移同时存在）。

## 验证要点（实机）
1. 阴天：背景是灰调阴天预设（组 5），不再是蓝底晴天；
2. 任意有云场景：云以肉眼可见的速度缓慢左移（近景云明显、远景云更慢）；
3. 「天气动效」关闭时：云定格（不漂移），但不黑屏。
