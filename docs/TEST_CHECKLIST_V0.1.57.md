# v0.1.57 实机测试清单

> 版本：v0.1.57（B 线修复 + C 线重构）
> 构建：dailyweather-v0.1.57.apk（14.76MB）
> 日期：2026-10-14

## 必测项（B1 修复验证）

### 1. 夜间场景（核心修复）
- **时间**：18:20 之后（日落后）
- **操作**：打开主屏
- **预期**：深蓝夜空背景（1_6_sunny-night），不是粉紫日落
- **验证点**：背景为深蓝色系，有月亮/星星/夜云元素

### 2. 日落卡时间
- **操作**：查看日落卡
- **预期**：显示今天的日出/日落时间（不是昨天）
- **验证点**：时间与实际日落时间一致（误差 ≤2 分钟）

### 3. 时段切换
- **操作**：日落前 17:00 打开，等到 17:30（日落）
- **预期**：17:26 日落时场景平滑切换到日落档（粉紫），18:20 后切换到夜档（深蓝）
- **验证点**：场景切换平滑，无闪烁/黑屏

## 回归项（C 线重构验证）

### 4. 雷闪动画
- **操作**：切换到雷暴天气（或等雷暴天）
- **预期**：闪电为 5 层 bolt 同时双峰闪 + 溶解显形，4.5s 周期
- **验证点**：闪电形态正确，无卡顿

### 5. 场景淡入
- **操作**：切换城市/天气
- **预期**：新场景元素 0.9s 内柔和淡入，不硬切
- **验证点**：云/太阳/月亮淡入自然

### 6. 云漂移
- **操作**：晴天/多云观察云层
- **预期**：云缓慢左移（近景快、远景慢），无硬切
- **验证点**：云漂移平滑，30fps 下无卡顿感

## 性能项（D 线验证）

### 7. 帧率
- **操作**：设置 → 开发者选项 → GPU 呈现模式分析
- **预期**：纯天空+云场景 30fps，雨/雪/雷满刷新率
- **验证点**：帧率曲线平稳，无掉帧

### 8. 耗电
- **操作**：正常使用 1 小时
- **预期**：耗电与 v0.1.55 相当或更低
- **验证点**：电池使用详情中每日天气占比无异常

## 已知限制

- 分钟级降水卡需 BYOK 彩云 token（共享 key 无分钟数据）
- 模拟器 GLES 3.1 无 GPU 粒子（设计内降级）
- 62 场景视觉验证待全量跑（当前只验了晴/多云/阴/雨/雪/雾/雷）
